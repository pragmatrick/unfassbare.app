# unfassbare.app
Unfassbare Wörter Generator und API

## API requests
Fettgedruckte Wörter werden pro Anfrage zufällig generiert.
- https://unfassbare.app/api/words/ = ["**UNFASSBAR**", "**SENSATIONELL**", ..., "**FANTASTISCH**"] (alle Wörter)
- https://unfassbare.app/api/words/?random=true&limit=2 = ["**PHÄNOMENAL**", "**ZAUBERHAFT**"]
- https://unfassbare.app/api/words/?random=true&limit=1 = ["**DELIZIÖS**"]
- https://unfassbare.app/api/greetings/?type=hey = "Einen **WUNDERSCHÖNEN** guten Morgen/Mittag/Abend!"
- https://unfassbare.app/api/greetings/?type=bye = "**Blendende** Grüße"
